# Code of Conduct

gbd is a small project, and this is a short code of conduct.

## Expectations

Be respectful and direct. Assume good faith. Critique code and ideas, not people. Welcome newcomers and questions; nobody was born knowing what a merge queue is.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, sexualised language or imagery, publishing others' private information, and sustained disruption of discussions. This applies in issues, pull requests, discussions, and any other space where you represent the project.

## Reporting

Report concerns privately to the maintainers through GitHub: open the maintainer's profile and use **Report abuse**, or use the repository's private vulnerability report form if that is the only private channel available to you. Reports are handled confidentially.

## Enforcement

Maintainers may edit, remove, or reject contributions and comments that violate this code, and may temporarily or permanently block contributors for behaviour they judge inappropriate, threatening, or harmful.

If the project grows, this will be replaced by the [Contributor Covenant](https://www.contributor-covenant.org/); the expectations will not change.
